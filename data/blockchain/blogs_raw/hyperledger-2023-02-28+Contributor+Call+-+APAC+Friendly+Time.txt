	Release updates	Release Rotations 2023
 
	23.1.1 proposed for March 8 - thoughts?	Ideally would include Goerli Shanghai config
	No objections to March 8 release date




	Work Updates	Shanghai Epic: https://github.com/hyperledger/besu/issues/4746	Ready for Sepolia and on track for mainnet


	Work started on EIP-6110: in-protocol deposits by external contributor https://github.com/hyperledger/besu/pull/5055	Appears to be done as part of the Ethereum Protocol Fellowship by Mikhail's mentee: https://hackmd.io/@doPpmyH4Ta-4Yc8pq3u-ZA/BkQKSAn2s
	Any reason not to include this on main using ExperimentEipsTime as a feature toggle?	Have further discussion on contributor discord






	Other Business	merge queue - any objections to enabling this?	the only change to how we currently work is you would have to manually squash commits on your branch PR rather than via the github UI - eg https://stackoverflow.com/questions/25356810/git-how-to-squash-all-commits-on-branch
	Sally has tested it out on a couple of repos - notes here https://github.com/hyperledger/besu/issues/5102 - I haven't come across any showstoppers
	it's essentially the same as enabling auto-merge, except that any additional "merge from main" actions are automated
	should reduce our CI spend, as well as reducing manual interventions
	Outcome: No objections. Sally to enable it after the next release with notes on squash merge instructions


	Final call to remove #besu-nodes Discord channel.	Previously mentioned 2022-12-06 Contributor Call - APAC Friendly Time

	One way would be give a couple of days deprecation and ask users with outstanding questions to move them over to #besu
	Outcome: Simon to ping Danno on concerns re: besu-nodes channel deprecation. No other objections. If objections are resolved then remove the channel.
