Execution client
Besu has support for Shandong testnet integrated on the main branch, so you only need to set --network=shandong and then you can define any of the existing CLI options as you need. E.g.
--network=shandong
--sync-mode=FULL
--data-path=[execution data directory]
--rpc-http-enabled=true
--engine-rpc-enabled=true
--engine-jwt-disabled=true
--rpc-http-api=ADMIN,DEBUG,ETH,NET,WEB3
