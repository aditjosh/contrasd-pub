Follow the Besu documentation contribution workflow when submitting a contribution.
The Besu documentation is built using Docusaurus and follows the ConsenSys documentation contribution guidelines for the following topics:
	Style guide
	Format Markdown
	Configure Docusaurus
	Add images
	Preview the docs
	Review contributions

You can contribute to or suggest improvements to these guidelines in the docs guide GitHub repository.
